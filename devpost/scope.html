VibeGuide Scope Approved

A taste-intelligent travel concierge: enter a city and a few cultural anchors you love, get a curated 1-day itinerary where every stop comes with a personalized explanation of why it fits your vibe.

🔥 The Unique Kernel

The cross-domain "Why It Fits Your Vibe" explanation. Qloo provides the taste intelligence; an LLM synthesizes it into a story: "Because you love Studio Ghibli and lo-fi hip hop, you'll appreciate the hand-painted signage, warm wood interior, and quiet back-alley location of this kissaten." The magic isn't the recommendation — it's the narrative bridge.

👤 Who It's For

An independent, culturally curious traveler (early 20s–30s) arriving in an unfamiliar major city. Tired of generic "Top 10" tourist lists that are completely blind to personal taste. Wants a personalized cheat sheet that gets them.

📦 Scope Boundaries

🟢 What We're Building (Now)
  • now Single-page app: one screen, one flow
  • now 2 cities (Tokyo, New York) — dropdown selector
  • now 2–3 cultural anchor inputs (music, film, vibe tag)
  • now "Generate My Day" button
  • now 4-stop 1-day itinerary (Morning → Night)
  • now "Why It Fits Your Vibe" LLM narrative per stop
  • now Graceful loading state during processing
  • now FastAPI → Qloo API → LLM → React pipeline
  • now Localhost deployment, clean README
🟡 Later (Worth Doing, Not Now)
  • later More cities (London, Paris, etc.)
  • later Thumbs-up/down feedback to refine results
  • later Shareable itinerary cards
  • later "Surprise Me" mode — vibe + budget → city suggestion
  • later User accounts and saved itineraries
🔴 Explicitly Cut
  • cut User auth / accounts — unnecessary friction for taste-in, itinerary-out PoC
  • cut Database — no persistence; every generation is stateless
  • cut Booking integrations — not a travel agent, it's a taste concierge
  • cut Mobile app — web on localhost for the demo
  • cut More than 2 cities — depth over breadth
  • cut Group trips — one person, one vibe, one day
